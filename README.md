# نشر السجل القانوني لفريق (Cloudflare Pages + D1)

هذه الحزمة تحتاج سطر أوامر (Terminal) على جهازك، لأن ميزة الرفع بالسحب والإفلات
في لوحة Cloudflare لا تدعم قواعد البيانات. الخطوات مرة واحدة فقط.

## المتطلبات
- تثبيت Node.js (من nodejs.org) إن لم يكن مثبتًا.
- حساب Cloudflare مجاني.

## الخطوات

1) افتح Terminal داخل مجلد هذه الحزمة، وسجّل دخولك:
```
npx wrangler login
```
سيفتح المتصفح لتسجيل الدخول لحساب Cloudflare.

2) أنشئ قاعدة البيانات:
```
npx wrangler d1 create legal-registry-db
```
سيعطيك الأمر `database_id`. افتح ملف `wrangler.toml` واستبدل
`REPLACE_WITH_YOUR_DATABASE_ID` بالقيمة التي ظهرت لك.

3) أنشئ الجداول على القاعدة الحقيقية (وليس محليًا):
```
npx wrangler d1 execute legal-registry-db --remote --file=schema.sql
```

4) انشر التطبيق:
```
npx wrangler pages deploy .
```
أول مرة سيسألك عن اسم المشروع — اكتب مثلًا `legal-registry`.

5) اربط قاعدة البيانات بالمشروع من لوحة التحكم:
   Cloudflare Dashboard → Workers & Pages → اختر مشروعك → Settings → Functions
   → D1 database bindings → Add binding:
   - Variable name: `DB`
   - D1 database: `legal-registry-db`
   ثم أعد النشر مرة أخرى بنفس أمر الخطوة 4 حتى يفعّل الربط.

6) افتح الرابط الذي أعطاك إياه Wrangler (مثل `legal-registry.pages.dev`).

## تسجيل الدخول لأول مرة

التطبيق الآن يتطلب تسجيل دخول. حساب المدير الافتراضي المضمّن في قاعدة البيانات:

- **اسم المستخدم:** `admin`
- **كلمة المرور:** `ChangeMe123!`

**غيّر كلمة المرور فورًا** بعد أول دخول من: الإعدادات → تغيير كلمة المرور.

## الصلاحيات (الأدوار)

من شاشة "المستخدمون" (تظهر فقط لحساب المدير)، يمكنك إضافة بقية أعضاء الفريق وتحديد دور كل واحد:

- **مدير (admin):** يرى كل المستندات، يضيف ويعدّل ويحذف، ويدير حسابات المستخدمين والصلاحيات.
- **محرر (editor):** يضيف ويعدّل المستندات، لكن لا يصل لشاشة إدارة المستخدمين.
- **مطالع فقط (viewer):** يكتفي بعرض المستندات والبحث فيها، دون إضافة أو تعديل أو حذف.

كما يمكن **تقييد أي محرر أو مطالع بإدارة واحدة فقط** (مثلًا "الموارد البشرية")، بحيث لا يرى أو يعدّل إلا مستندات تلك الإدارة تحديدًا. اتركه بدون تقييد ليرى كل الإدارات.

## تحديثات لاحقة
أي تعديل على التطبيق مستقبلًا: عدّل الملفات ثم أعد فقط:
```
npx wrangler pages deploy .
```

## ملاحظة أمان
التطبيق الآن يطلب اسم مستخدم وكلمة مرور حقيقيين قبل عرض أي بيانات، وكل طلب للخادم
يتحقق من صلاحية الجلسة. لطبقة حماية إضافية اختيارية (تقييد الدخول على نطاق بريد
شركتكم قبل حتى الوصول لشاشة الدخول)، يمكنك أيضًا تفعيل **Cloudflare Access** من
لوحة التحكم (Zero Trust → Access → Applications) دون تعديل أي كود.
